# Food photography credits, licences and provenance

**Verified:** 2026-11-02 · **Imagery:** real, camera-captured photographs only · **AI-generated or synthetic images:** none

The atlas presents four photographic acts per dish — I. origin & history, II. ingredients, III. recipe & making, IV. the finished dish. Every image is a photograph by a named photographer, published on Wikimedia Commons under a licence that permits reuse (CC0 / public domain / CC BY / CC BY-SA — no non-commercial and no no-derivatives terms). Creator, licence, licence URL and the source file page were checked on Commons for every file and are shown in the interface next to the photograph.

Photographs are served from the Wikimedia Commons image CDN at the project's standard thumbnail widths (500 / 960 / 1280 / 1920 px), with a colour grade and a crop applied by the site. No pixels have been generated, added, removed or composited. The WebP files under `public/images/dishes/` are credited copies of the same Commons originals and are used only as a fallback if the CDN cannot be reached.

Where no photograph could be verified as **both** unmistakably the dish and free to reuse, the dish shows an explicit *no verified photograph* state. Nothing is substituted — no AI image, no photograph of a different dish, no illustration.

## Reuse obligations

- **CC BY / CC BY-SA:** retain the photographer credit, the licence name and links to both the licence and the source file. Share-alike adaptations must be distributed under the same licence; this ledger records that obligation with each file.
- **Modifications:** colour correction and cropping only.
- Attribution travels with every image in the interface — each frame links to its source file and licence, and each dish carries a full photography-credits ledger.

## Selection method

Photographs were reviewed visually before selection, not chosen from search rankings. Candidates were rejected when the dish identity was ambiguous (for example a photograph of a different regional preparation), when only a low-resolution thumbnail existed, or when the licence could not be verified. Several dishes in this atlas have no verified finished-dish photograph and are marked accordingly rather than illustrated.
